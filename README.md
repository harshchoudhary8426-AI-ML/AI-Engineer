# AI-Engineer

Portfolio website of an AI/ML Engineer featuring machine learning projects, technical skills, certifications, and an interactive resume section.

This project is a clean, responsive personal portfolio for Harsh Choudhary, built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on GitHub Pages
1. Push the project to GitHub.
2. Go to **Settings → Pages**.
3. Select the `main` branch and root folder.
4. Save. GitHub will publish the site.

## Customize
- Replace the profile image in the hero section if needed.
- Update project links to your GitHub repositories or live demos.
- Keep the resume PDF in the project root for the resume modal.
- Add or update certifications, experience, and contact details as needed.
